# Auction House

Auction House is a student-only online auction platform built for Noroff students.

Users can browse auction listings, search for items, place bids, and manage their own listings. Registered users can also manage their profile and view listings they have created or bid on.

## Features

- Browse active auction listings
- Search for listings
- Sort and filter listings
- View individual auction listings
- View bid history
- Register with a Noroff student email
- Log in and log out
- View available credits
- Create auction listings
- Edit and delete your own listings
- Place bids on other users' listings
- View your own listings and bids
- Edit profile bio, avatar and banner
- Responsive design for desktop and mobile

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- Bootstrap 5
- Noroff Auction House API v2

## Getting Started

Clone the repository and open the project in Visual Studio Code.

The project can be run locally using a local development server such as the VS Code Live Server extension.

## Design

The website was designed in Figma before development.

The visual style uses a retro game-show inspired design with bold colours, chunky borders and playful typography.

## Deployment

The website is deployed using GitHub Pages.
